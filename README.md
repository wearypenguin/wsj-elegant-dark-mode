# WSJ Elegant Dark Mode Website

A promotional website for the WSJ Elegant Dark Mode Chrome extension.

## What it does

This website provides information about the WSJ Elegant Dark Mode extension, which applies a sophisticated dark theme to The Wall Street Journal website.

## Features

- Clean, dark-themed design matching the extension's aesthetic
- Highlights key features and benefits
- Links to Chrome Web Store for easy installation
- Privacy policy page
- Responsive design

## Files

- `index.html` - Main landing page with extension information
- `privacy.html` - Privacy policy page
- `style.css` - Stylesheet matching the dark theme design
- `Marquee-promo-tile.png` - Banner image
- `Small-promo-tile.png` - Preview image

## Development

The site uses a simple, static HTML/CSS design that can be hosted on GitHub Pages or any static hosting service.
